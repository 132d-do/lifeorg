# LifeOrg 功能闭环与专职 Agent 完善

## Why
现有详情按钮存在提示型死路；新用户被写入虚构示例目标；会议输入缺少容量与选项；Agent 专职输出未被校验。已有 127 项测试通过不等于功能闭环完整。

## What Changes
- 以真实数据和明确下一步重建首页、目标/决策详情、洞察与设置。
- 四个真实 SDK Agent 共用可审阅的角色契约，按会议类型执行明确议程，校验身份与证据，支持综合阶段继续补问。
- 会议准备收集容量、截止日、替代方案和成功标准，保留来源目标/决策；重复提交及失败可恢复。
- 取消自动写入虚构目标/决策；已有记录不删除。
- 运行中周期不再要求再次新建周期，避免建议无法批准；任何业务写入仍需用户批准。

## Impact
保留 D1 模式和历史记录；无破坏性迁移；API 密钥仍只用服务端私密环境变量。GitHub 分为规格、Agent 内核、功能体验三层关联提交/PR。线上真实调用验收依赖密钥，不伪造通过。
